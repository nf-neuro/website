**[BIDS](https://bids-specification.readthedocs.io/en/stable/)**, or **B**rain **I**maging **D**ata **S**tructure, is a standard data organization and description framework in neuroimaging. It helps researchers and database managers to align their datasets to a common format, which makes them easier to share and process.
